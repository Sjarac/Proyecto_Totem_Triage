# Tótem: Evaluación Fisica Automatizada
El proyecto a continuación propone el desarrollo de un Tótem Inteligente de Triage Automatizado con Inteligencia Artificial integrada, orientado a optimizar el flujo de admisión y categorización en los servicios de urgencia hospitalaria. La solución aborda la latencia en la atención inicial mediante un sistema ciberfísico de autoatención que permite a los pacientes registrar su telemetría biométrica y antecedentes clínicos de forma previa a la evaluación presencial del personal de enfermería.El tótem realiza la adquisición digital de variables fisiológicas críticas: presión arterial, frecuencia cardíaca, saturación de oxígeno (SpO_2), temperatura corporal, peso y altura, complementadas con un módulo interactivo para el levantamiento de antecedentes mórbidos y patologías crónicas. Posteriormente, un pipeline de inferencia basado en modelos de aprendizaje automático analiza el vector de datos clínicos y genera una recomendación estructurada del nivel de urgencia, alineada con los protocolos estandarizados de triage (como ESI o Manchester) y las políticas operativas del centro de salud, entregando soporte objetivo a la decisión clínica para la priorización de pacientes.Este proyecto articula el desarrollo de software moderno, integración de hardware biomédico mediante Internet de las Cosas (IoT), gestión de bases de datos relacionales e Inteligencia Artificial, respondiendo a una problemática crítica en la gestión hospitalaria: maximizar el rendimiento operativo del proceso de clasificación y reducir los tiempos de respuesta en la ventana de atención inicial de urgencias.
